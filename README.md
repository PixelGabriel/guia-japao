# Japão sem perrengue

Guia mobile-first em português para brasileiros viajando ao Japão.

## Conteúdo

- Telefones de emergência 110, 119 e 118
- Japan Visitor Hotline e plantão do Consulado-Geral do Brasil em Tóquio
- Frases em japonês com romanização, tradução, copiar e ouvir
- Cartão de emergência salvo somente no `localStorage`
- Checklist de viagem persistente
- Orientações para terremoto, tsunami e objetos perdidos
- PWA para uso offline

## Rodar localmente

```bash
python3 -m http.server 8080
```

Acesse `http://localhost:8080`.

## Fontes

- JNTO — Japan Visitor Hotline
- JNTO — Staying Safe in Japan
- Japan Coast Guard
